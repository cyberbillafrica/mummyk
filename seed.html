Admin Sign In

This tool writes to Firestore, so it needs the admin login (same as the admin dashboard).

1. Import Products (bulk)

Paste a JSON array of products below, then click Import Products. Each product becomes a document in the products collection.

Expected format (one object per product):

{
  "name": "Floral Summer Dress",
  "price": 7500,
  "category": "Clothes",          // Clothes | Shoes | Bags | Others
  "sizes": ["2yrs", "4yrs", "6yrs"],
  "mediaUrl": "https://res.cloudinary.com/…/image.jpg",
  "mediaType": "image",            // image | video
  "youtubeUrl": ""                 // optional
}

💡 Tip: upload photos/videos in the admin dashboard first (or via the Cloudinary Media Library), then paste the Cloudinary URLs here. createdAt is added automatically.

2. Seed Business Settings

Creates (or updates) the single settings document using the defaults from js/config.js — WhatsApp number, OPAY bank details and the current announcement. You can fine-tune everything afterwards in Admin → Business Settings.
